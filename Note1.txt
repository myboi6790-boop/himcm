Degree:

Weighted paths: "shortest" mans smallest total weight(a path with more edges can still be faster or cheaper)
Weight examples: distance, travel time,cost,risk

Dijkstra's shortest path algorithim:
Initialize: Set distance(source)=0 every other distance = infinity
Choose a node: Among unsettled nodes, select the one with smallest tenative distance
Relax its edges: Try distance(u) +w(u,v); keep it if it imrpoves distance(v)
Settle the node: Its shortest distance is now final
Repeat: Stop when the target issettled or all reachabe nodes is settled

Kruskal's algorithim on the same network:
sort edges from lightest to heaviest: add an edge only if it does not create a cycle
